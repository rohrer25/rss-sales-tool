HOW TO UPDATE YOUR RSS SALES TOOL ON GITHUB PAGES
==================================================

You already have the site live at rohrer25.github.io/rss-sales-tool
This update keeps the SAME URL and the SAME QR code — nothing to
reinstall on the iPad.

STEP 1 - Download the zip
  Grab: rss-sales-tool-github.zip

STEP 2 - Unzip it
  You'll get ONE tool:
    - index.html                       (THE sales tool — always this file)
    - pdfs/                            (all the PDFs)
    - sw.js, vendor/, icons/, manifest.webmanifest

  NOTE (2026-09-24): there used to be a second file,
  RSS-Fall-2026-Sales-Tool.html, described here as "the main sales tool".
  That was wrong — index.html is the only tool. The old file has been
  retired to a redirect, so old bookmarks and QR codes still work.

  IMPORTANT — upload index.html by itself. Don't drag in a whole folder
  from Finder/Explorer or the browser will rename it "index (1).html",
  which is NOT served. That is what caused earlier duplicates in this repo.

STEP 3 - Push to GitHub
  Option A (easiest — via the web):
    1. Go to github.com/rohrer25/rss-sales-tool
    2. Open index.html -> pencil (Edit) -> paste the new contents -> Commit
       (editing in place avoids duplicates entirely)
    3. Or: "Add file" -> "Upload files", drop in ONLY the files that changed
    4. Commit message: "Fall 2026 sales tool - unified iPad+desktop"
    5. Click "Commit changes"
    6. Wait 1-2 minutes for GitHub Pages to rebuild
    7. Open rohrer25.github.io/rss-sales-tool in Safari — done.

  Option B (git command line):
    cd rss-sales-tool
    unzip -o rss-sales-tool-github.zip
    git add .
    git commit -m "Fall 2026 sales tool - unified iPad+desktop"
    git push

STEP 4 - iPad (already installed)
  If you already added the tool to the iPad home screen, just tap the
  icon — it loads the new version automatically. If not, see
  MAKE-IT-AN-APP.txt.

That's it. Same URL. Same QR code. New unified tool.
